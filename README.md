# 🎬 Movie Recommendation System

A machine learning-powered movie recommendation system using **Collaborative Filtering** and **Content-Based Filtering** techniques, with a Flask web interface.

Supports two data modes — jump straight in with synthetic data, or plug in a real Kaggle dataset for production-quality recommendations.

## 📊 Data Options

Choose **Option A** to run instantly with no setup, or **Option B** for real-world data.

---

### Option A — Synthetic Data (auto-generated, no download)

The app ships with a built-in dataset of **50 popular movies** and **~600 simulated ratings** across 30 users. No extra steps needed — just start the server and go.

```bash
cd backend
python app.py
```

Visit **http://localhost:5000**. The app detects that no Kaggle data is present and uses the synthetic dataset automatically.

**Good for:** exploring the UI, running tests, development, demos.

---

### Option B — Real Kaggle Data (step-by-step)

**Step 1 — Download the dataset from Kaggle**

Go to one of the dataset pages above, click **Download**, and extract the ZIP.

**Step 2 — Place the CSV files**

Create the folder and copy the files in:
```
backend/data/kaggle/
```

For **MovieLens**, you need:
```
backend/data/kaggle/movies.csv
backend/data/kaggle/ratings.csv
backend/data/kaggle/tags.csv       ← optional, improves recommendations
```

For **TMDB**, you need:
```
backend/data/kaggle/movies_metadata.csv
backend/data/kaggle/ratings_small.csv
backend/data/kaggle/credits.csv        ← optional
backend/data/kaggle/keywords.csv       ← optional
```

**Step 3 — Run the processing pipeline**
```bash
python process_data.py
```

The script auto-detects which dataset you have and runs the full pipeline.

---

#### Step 5 — Start the app (same for both methods)

```bash
cd backend
python app.py
```

Visit **http://localhost:5000**. The app automatically detects the processed Kaggle files and uses them instead of the synthetic data. The data source (Kaggle or Sample) is shown via the `/api/datasource` endpoint.

---

#### What `process_data.py` does

The pipeline runs 7 steps end-to-end:

| Step | What happens |
|------|-------------|
| **Load** | Reads raw CSVs; extracts year from title; parses JSON-encoded genres, cast, keywords |
| **Clean** | Deduplicates movies and ratings; clips ratings to [0.5 – 5.0]; drops nulls |
| **Enrich** | Merges tags / credits / keywords into a unified description field for the content model |
| **Feature engineering** | Adds `avg_rating`, `rating_count`, Bayesian score, per-user mean-centred ratings |
| **Validate** | Checks schema integrity and data quality; warns on soft issues |
| **EDA report** | Prints rating distribution, top genres, most-rated movies, year distribution |
| **Save** | Writes `processed_movies.csv`, `processed_ratings.csv`, `processing_report.txt` |

## 🧠 Recommendation Techniques

### Collaborative Filtering
Builds a **user × movie rating matrix** and uses **cosine similarity** between users to predict ratings for unseen movies. Recommends what similar users enjoyed.

- Best for: personalised "For You" recommendations
- Requires: rating history for the user

### Content-Based Filtering
Applies **TF-IDF vectorisation** on each movie's genres, description, cast, and keywords, then ranks by **cosine similarity** to a seed movie.

- Best for: "More like this" recommendations
- Requires: no rating history
